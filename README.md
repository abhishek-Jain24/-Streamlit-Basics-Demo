# # Streamlit Basics Demo
 A beginner-friendly Python application demonstrating the basic features of Streamlit.

## Features

- Titles, headers, Markdown, and captions
- Code, JSON, and metric displays
- Sidebar navigation
- Text and number inputs
- Sliders and checkboxes
- Radio buttons, selectboxes, and multiselects
- Color picker
- Buttons and a sample registration form
- Columns and expandable sections
- Success, information, warning, and error messages
- Progress bar
- Text file upload and preview
- Sample text file download

## Technology

- Python
- Streamlit

## Installation

```bash
pip install -r requirements.txt
```

## Run the App

```bash
streamlit run app.py
```

## Project Purpose

This project was created to practice building interactive interfaces
using Python and Streamlit.

## Limitations

- The registration form displays a confirmation message only.
- Registration details are not stored in a database.
- The progress bar displays a fixed demonstration value.
- The file uploader is intended for UTF-8 text files.
